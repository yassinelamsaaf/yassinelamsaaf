## About

### Advalio

Supervision and control platform for a **5G SA testbed** (`free5GC` + `srsRAN`), built to replace day-to-day manual CLI operation.

- Spring Boot 3 modular monolith handling SSH control, JWT authentication with RBAC, and a full audit trail
- React + Vite frontend streaming live state over WebSocket / STOMP
- AI Copilot built on RAG (`pgvector` + Ollama) with tool calling, where the agent proposes an action and only executes after explicit confirmation

### B2BLink (SmartAlert)

Upgraded SmartAlert, a personalised alert solution for automotive offers.

- Multi-channel authentication across email, phone, and Google / Facebook OAuth
- Multilingual customer-support chatbot handling French and Arabic
- Profile customisation and account settings management

### INE Alumni Platform

Alumni and student networking platform (professional directory, job offers, events), developed alongside professional alumni contributors.

- Spring Boot, Spring Security with JWT, JPA / Hibernate, PostgreSQL
- React with Vite and Tailwind CSS, containerised with Docker
